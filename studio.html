استودیو نویدیکس

پرامپتت را با زبان سینما کامل می‌کند و مدل مناسبِ همان کار را انتخاب می‌کند. لازم نیست بدانی کدام مدل برای چه خوب است — همین انتخاب، کارِ نویدیکس است.

کلید رایگان خودت را بگذار — نامحدود می‌شود

دو دقیقه وقت می‌برد و یک بار برای همیشه است. بعدش دیگر سقف روزانه نداری، چون روی سهمیه‌ی خودت کار می‌کند.

  1. دکمه‌ی زیر را بزن — صفحه‌ی گوگل باز می‌شود
  2. با همان جیمیلی که همیشه استفاده می‌کنی وارد شو
  3. روی Create API key بزن
  4. اگر پرسید کدام پروژه، Create API key in new project را بزن
  5. کلیدِ ساخته‌شده را کپی کن و پایین همین‌جا بچسبان
باز کردن صفحه‌ی کلید گوگل ←

کلیدت پیش خودت می‌ماند. جایی ذخیره نمی‌شود جز همین مرورگر، و به سرور نویدیکس فرستاده نمی‌شود — ما اصلاً سروری نداریم که بفرستد. مرورگرت مستقیم با گوگل حرف می‌زند. هر وقت خواستی، پاکش کن.

هنوز چیزی نساخته‌ای.

تصویرها را مدل‌های آزادِ دیگران می‌سازند؛ آنچه نویدیکس اضافه می‌کند انتخاب مدل و کاملْ‌کردنِ پرامپت است. اگر می‌خواهی خودت این کار را یاد بگیری، آناتومی یک پرامپت خوب همین را از پایه می‌گوید.
