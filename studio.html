استودیو نویدیکس

فارسی بنویس. نویدیکس ترجمه‌اش می‌کند، با زبان سینما کاملش می‌کند و مدل مناسبِ همان کار را انتخاب می‌کند — و هر سه را هم نشانت می‌دهد. لازم نیست بدانی کدام مدل برای چه خوب است.

کیفیت بهتر می‌خواهی؟ FLUX را روشن کن — رایگان

FLUX.1 schnell بهترین مدلِ تصویری است که رایگان در دسترس است. روی Cloudflare اجرا می‌شود و کارت بانکی نمی‌خواهد.

مرورگر اجازه ندارد مستقیم Cloudflare را صدا بزند، پس یک واسطه‌ی کوچک روی حساب خودت می‌سازی. ده دقیقه، یک بار برای همیشه — و اینطوری توکنت اصلاً وارد مرورگر نمی‌شود.

  1. در Cloudflare: Compute ← Workers & Pages ← Create
  2. Start with Hello World! را بزن، اسمی مثل navidix-flux بگذار و Deploy کن
  3. حالا Edit code را بزن، هرچه در ویرایشگر هست پاک کن و کدِ زیر را جایش بچسبان، بعد Deploy
  4. برگرد به همان Worker ← Settings ← Bindings ← Add binding ← Workers AI ← نامش را دقیقاً AI بگذار ← ذخیره
  5. آدرس Worker را کپی کن — چیزی شبیه navidix-flux.…workers.dev — و پایین بچسبان
export default {
  async fetch(req, env) {
    const cors = {
      "Access-Control-Allow-Origin": "*",
      "Access-Control-Allow-Headers": "content-type",
      "Access-Control-Allow-Methods": "POST, OPTIONS"
    };
    if (req.method === "OPTIONS") return new Response(null, { headers: cors });
    if (req.method !== "POST")
      return new Response("POST only", { status: 405, headers: cors });

    const body = await req.json().catch(() => ({}));
    if (!body.prompt)
      return Response.json({ error: "no prompt" }, { status: 400, headers: cors });

    const out = await env.AI.run("@cf/black-forest-labs/flux-1-schnell", {
      prompt: body.prompt,
      steps: body.steps || 4
    });
    return Response.json(out, { headers: cors });
  }
};

آدرس Worker پیش خودت می‌ماند. جایی ذخیره نمی‌شود جز همین مرورگر. و مهم‌تر: توکن Cloudflare هیچ‌وقت وارد این صفحه نمی‌شود — داخل Worker خودت می‌ماند، جایی که فقط تو دسترسی داری. آن توکنی که ساختی هم دیگر لازم نیست؛ می‌توانی پاکش کنی.

هنوز چیزی نساخته‌ای.

تصویرها را مدل‌های آزادِ دیگران می‌سازند؛ آنچه نویدیکس اضافه می‌کند انتخاب مدل و کاملْ‌کردنِ پرامپت است. اگر می‌خواهی خودت این کار را یاد بگیری، آناتومی یک پرامپت خوب همین را از پایه می‌گوید.
